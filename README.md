# 中南铁道实验台

面向中南大学铁道工程本科生的实验数据分析、动态演示、网络数据摘录和实验报告生成软件。

## 本科四年实验

- 大一、 大二、大三、大四各 24 个实验，共 96 个本科实验模块。
- 12 个实验板块：工程测量、土木材料、基础力学、土工与地质、结构试验、铁路选线、轨道结构、路基工程、桥隧工程、铁路动力与检测、数字铁路、综合设计。
- 每个实验包含原理说明、公式变量、仪器、推荐步骤、安全注意、交互模型和示例数据。

## 报告和数据分析

- CSV 导入、坐标轴映射、统计量、线性拟合、残差、峰值和异常点检测。
- 每次导入数据自动生成一份独立编号的详细报告。
- 报告包含实验原理、方法、统计结果、不确定度、误差、改进建议和批次比较。
- 支持 Markdown 复制与下载。

## 网络数据摘录

- 从 World Bank Indicators API 获取铁路营业里程、货运周转量和客运周转量。
- 直接从公开 CSV/JSON URL 导入数据；支持识别 OpenAlex、Crossref 等 API 常见数组结构。
- 可摘录允许浏览器跨域访问的公开网页正文。
- 网络结果会生成新的实验数据报告版本。

## 文献与论文

- 使用 Crossref 和 OpenAlex 检索公开学术元数据。
- 引用库、BibTeX 导出、批次参考引用。
- 将详细实验报告和所选文献组合生成论文初稿。

## 运行

在程序目录运行：

```powershell
python -m http.server 8010
```

然后访问 `http://127.0.0.1:8010/`。

## 数据来源与边界

- 中南大学土木工程学院培养方案列表：<https://civil.csu.edu.cn/bksjy/pyfa.htm>
- 学院当前公开页面未提供可直接访问的逐门实验项目附件，因此 96 个实验为铁道工程本科教学框架下的实验映射。
- 具体实验名称、学期和开设要求应以中南大学土木工程学院当年实验教学安排为准。
- 网络数据必须来自公开、可合法访问且允许跨域读取的来源。系统不绕过登录、付费墙或访问限制。
- 论文初稿和报告均为写作辅助，提交前需要人工核对。
