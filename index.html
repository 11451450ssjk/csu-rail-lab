        # 论文工作台

1. 先导入实验数据并生成详细报告；
2. 在“文献与引用”中检索并加入相关论文；
3. 选择报告、论文类型和引用格式；
4. 点击“生成论文初稿”。

论文将包含摘要、引言、实验方法、结果分析、讨论、结论和参考文献。系统仅使用已导入数据和已选择的文献元数据。
